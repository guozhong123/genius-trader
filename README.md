# 天才交易员

自选股票 / 基金盯盘 Chrome 扩展（A股 · 港股 · 美股 · 场外基金）。

## 本地安装

```bash
npm install
npm run build
```

1. 打开 Chrome `chrome://extensions`
2. 开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本项目的 `dist` 目录
4. 点击扩展图标，进入全屏盯盘页

## 功能

- 自选股票 / 基金：分组（拖拽、改名、删除）、涨跌排序、置顶
- 大盘指数勾选展示（含黄金、白酒等）
- 分时 / 日周月 K、主力资金、板块柱图、涨跌榜、52etf 热力图
- **止损提醒**：详情里设止损价，触及/接近时顶部横幅 + 列表角标
- **支撑 / 压力标注**：可手填或按近期 K 线自动估算，画在分时与 K 线上
- **事件日历**：非农 / CPI（近似） / FOMC 窗口提示，一键查看近三周
- 左侧重大消息（宏观 + 科技，少而精，约 20 分钟刷新）
- 实时简析：持仓涨跌 + 科技龙头

## 说明

行情与快讯来自东方财富等公开接口，仅供学习与个人参考，**不构成投资建议**。CPI 日期为常用区间近似，请以官方日历为准。
